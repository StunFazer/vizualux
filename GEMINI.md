# Vizualux Project Guidelines

## Project Identity & Naming
- The official project name is **Vizualux**.
- Never reference the internal directory codename `charming-curie` in user-facing files, terminal outputs, scripts, documentation, or HTML titles.
- Public Repository: `https://github.com/StunFazer/vizualux.git`
- Live Demo: `https://vizualux.neocities.org`

## Documentation & Formatting Standards
- Do NOT use emojis in `README.md` or any other documentation files.
- Maintain clean, professional, text-based typography and standard GitHub-flavored Markdown formatting.
